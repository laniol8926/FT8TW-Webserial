4. JS8 protocol implementation — wasm/vendor/ft8tw/js8/, web/js/js8/
-------------------------------------------------------------------------------
   Implemented by FT8TW (BV6LC) for interoperability with the JS8 protocol
   defined by JS8Call. Protocol constants (LDPC (174,87) generator matrix and
   column order, Costas arrays, CRC-12 parameters, varicode tables) are taken
   from JS8Call as protocol facts required for interoperability.
   FT8TW 為與 JS8Call 定義的 JS8 協定互通而實作；LDPC 生成矩陣、Costas 序列、
   CRC-12 參數、varicode 表等協定常數取自 JS8Call，屬互通所需的協定事實。

17. JTTY protocol implementation — wasm/src/jtty/, web/js/jtty/, web/decoder/jttydecoder.mjs
-------------------------------------------------------------------------------
   Implemented by FT8TW (BV6LC) for interoperability with the JTTY mode of
   WSJT-X 3.2 (K1JT et al.). Clean-room implementation: written only from the
   published WSJT-X User Guide, third-party prose descriptions of the protocol,
   and black-box analysis of data produced by the WSJT-X program (tone
   sequences, packed payloads and audio recordings). No source code of WSJT-X
   or of any other JTTY implementation was consulted. Protocol constants (sync
   sequence, CRC-12 polynomial, convolutional code generators, character table
   and message layout) are protocol facts required for interoperability.
   This implementation is licensed under the MIT License like the rest of this
   repository. Callsign packing reuses ft8_lib (section 1).
   FT8TW 為與 WSJT-X 3.2 的 JTTY 模式互通而以 clean room 方式實作：只依據 WSJT-X 使用手冊、
   第三方的文字描述，以及對 WSJT-X 程式輸出資料（tone 序列、酬載、錄音）的黑箱分析，
   未參考 WSJT-X 或任何 JTTY 實作的原始碼；同步序列、CRC、卷積碼、字元表等協定常數屬互通所需的協定事實。
   本實作與 repo 其他部分同為 MIT 授權；呼號編碼沿用 ft8_lib（第 1 節）。
